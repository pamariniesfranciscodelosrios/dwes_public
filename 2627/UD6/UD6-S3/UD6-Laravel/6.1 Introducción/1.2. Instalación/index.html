    Versión de referencia para una práctica reproducible

    Esta guía fija Laravel 12.x para conservar la compatibilidad con el mínimo PHP 8.2 de los apuntes. No se presenta como la versión más reciente. Usa la misma versión en todos los equipos; registra la versión exacta instalada.

    1. Introducción

    Antes de escribir una sola línea de código Laravel, necesitas tener el entorno de desarrollo listo. En esta lección cubriremos la instalación completa en Windows, macOS y Linux. Sigue las instrucciones de tu sistema operativo y al final tendrás Laravel corriendo en tu máquina.

    2. Requisitos previos

    Independientemente del sistema operativo, Laravel necesita lo siguiente:

    Requisito Versión mínima
    PHP 8.2
    Composer 2.x
    Node.js + NPM Versión LTS compatible con Vite
    Base de datos MySQL 8.0 / PostgreSQL 13 / SQLite 3

    3. Instalación en Windows

    Opción 1: Laragon (recomendada para principiantes)

    Laragon es el entorno de desarrollo más popular para Laravel en Windows. Instala PHP, MySQL, Nginx/Apache y Composer en un solo clic.

    1. Descarga Laragon desde laragon.org.
    2. Ejecuta el instalador y sigue los pasos (siguiente, siguiente, instalar).
    3. Abre Laragon y haz clic en “Start All”.
    4. Verifica PHP con php -v.
    5. Verifica que Composer está disponible:
    composer -V
# Composer version 2.x.x

    Opción 2: Manual con XAMPP + Composer

    Si ya usas XAMPP:

    1. Descarga XAMPP con PHP 8.2 desde apachefriends.org.
    2. Agrega C:\xampp\php a la variable de entorno PATH:
    3. Panel de control → Sistema → Configuración avanzada del sistema → Variables de entorno.
    4. Edita la variable Path y agrega la ruta de PHP.
    5. Descarga e instala Composer desde getcomposer.org.
    6. El instalador de Composer detectará automáticamente tu PHP de XAMPP.

    Crear tu primer proyecto en Windows

    Abre la terminal de Laragon (o CMD/PowerShell) y ejecuta:

    # Navega a la carpeta de proyectos
cd C:\laragon\www

# Crea el proyecto
composer create-project laravel/laravel mi-proyecto "^12.0"

# Entra al proyecto
cd mi-proyecto

# Arranca el servidor
php artisan serve

    Abre tu navegador en http://localhost:8000 y verás la página de bienvenida de Laravel.

    4. Instalación en macOS

    Opción 1: Homebrew (recomendada)

    Homebrew es el gestor de paquetes más popular para macOS. Si no lo tienes instalado, ábrelo desde la terminal:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    Una vez instalado Homebrew, instala PHP:

    brew install php

# Verifica la instalación
php -v
# Comprueba que la versión instalada cumple PHP >= 8.2

    Instalar Composer en macOS

    # Descarga el instalador de Composer
curl -sS https://getcomposer.org/installer | php

# Mueve Composer a una ubicación global
sudo mv composer.phar /usr/local/bin/composer

# Verifica
composer -V

    Opción 2: Laravel Herd

    Laravel Herd es la solución oficial de Laravel para macOS. Instala PHP, Nginx y todo lo necesario con una interfaz gráfica muy sencilla.

    1. Descarga Herd desde herd.laravel.com.
    2. Abre la aplicación e instala los componentes que te pida.
    3. Herd agrega automáticamente PHP y Composer a tu PATH.

    Crear tu primer proyecto en macOS

    # Navega a tu carpeta de proyectos
mkdir -p ~/Sites
cd ~/Sites

# Crea el proyecto
composer create-project laravel/laravel mi-proyecto "^12.0"

# Entra al proyecto y arranca el servidor
cd mi-proyecto
php artisan serve

    5. Instalación en Linux

    Las instrucciones aquí son para Ubuntu/Debian. Si usas Fedora, Arch u otra distribución, los nombres de los paquetes pueden variar ligeramente.

    Paso 1: Actualizar el sistema

    sudo apt update && sudo apt upgrade -y

    Paso 2: Instalar PHP y extensiones

    Usa los repositorios de tu distribución y comprueba primero que ofrecen PHP 8.2 o superior. Estas órdenes usan los nombres genéricos de paquetes de Ubuntu/Debian; no añadas un PPA de Ubuntu a Debian.

    sudo apt install php-cli php-common php-mysql php-sqlite3 php-xml php-curl php-mbstring php-zip php-bcmath unzip git
php -v
php -m

    Si la versión disponible es inferior a 8.2, utiliza un entorno actualizado antes de continuar. SQLite requiere el controlador pdo_sqlite.

    Paso 3: Instalar Composer

    # Descarga e instala Composer globalmente
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
sudo chmod +x /usr/local/bin/composer

# Verifica
composer -V

    Paso 4: Instalar MySQL (opcional, puedes usar SQLite para empezar)

    sudo apt install -y mysql-server

# Asegurar la instalación
sudo mysql_secure_installation

# Iniciar el servicio
sudo systemctl start mysql
sudo systemctl enable mysql

    Paso 5: Crear el proyecto

    mkdir -p ~/projects
cd ~/projects

composer create-project laravel/laravel mi-proyecto "^12.0"

cd mi-proyecto
php artisan serve

    6. Usar el instalador global de Laravel

    En cualquier sistema operativo, una vez que tienes Composer, puedes instalar el instalador global de Laravel:

    composer global require laravel/installer

    Consulta la ruta real de ejecutables de Composer:

    composer global config bin-dir --absolute

    Añade el directorio que devuelve a PATH en tu sistema y abre una terminal nueva. No presupongas que siempre será ~/.composer/vendor/bin.

    Con el instalador global se puede ejecutar laravel new mi-proyecto. Puede instalar una versión diferente a la fijada en esta guía; para el trabajo común usa el comando Composer con "^12.0".

    El instalador interactivo te preguntará qué stack quieres usar (Blade, Livewire, Inertia/Vue, Inertia/React), si quieres autenticación y qué base de datos prefieres.

    7. Verificar que todo funciona

    Después de crear tu proyecto, verifica que la estructura básica está correcta:

    # Dentro de la carpeta del proyecto
php artisan --version
# Laravel Framework 12.x.x

php artisan serve
# INFO  Server running on [http://127.0.0.1:8000].

    Abre http://localhost:8000 en tu navegador. Deberías ver la pantalla de bienvenida de Laravel con el logo y la versión.

    8. Instalar Node.js (para assets front-end)

    Laravel usa Vite para compilar assets (CSS y JavaScript). Para ello necesitas Node.js:

    Instala una versión LTS compatible con el Vite del proyecto desde Node.js o un gestor de versiones que ya tengas configurado. Comprueba los requisitos engines si npm informa de incompatibilidad.

    node -v
npm -v

    Una vez instalado Node, dentro de tu proyecto Laravel instala las dependencias de front-end:

    npm install
npm run dev  # inicia el servidor de Vite en modo desarrollo

    9. Resumen de comandos esenciales

    # Crear un nuevo proyecto
composer create-project laravel/laravel nombre-proyecto "^12.0"
# o
laravel new nombre-proyecto

# Arrancar el servidor de desarrollo
php artisan serve

# Ver la versión de Laravel
php artisan --version

# Instalar dependencias de front-end
npm install && npm run dev

    ¡Ya tienes Laravel instalado! En la siguiente lección exploraremos en detalle la estructura de carpetas del proyecto para entender qué hace cada directorio y archivo.

    Alternativa para comprobar los recursos compilados

    npm run build genera los recursos de producción. Después puedes comprobarlos con el servidor PHP sin mantener npm run dev abierto. php artisan serve es un servidor de desarrollo.

    10. Resolución de incidencias

    Síntoma Comprobación Actuación
    PHP o Composer no se reconoce php -v, composer -V en una terminal nueva Revisar PATH y el ejecutable seleccionado.
    Falta un controlador de SQLite php -m, php --ini Activar/instalarpdo_sqlite en el PHP de la terminal.
    Puerto 8000 ocupado Mensaje de Artisan Usarphp artisan serve --port=8080 y abrir ese puerto.
    Falta la clave de aplicación Revisar.env sin publicarlo Ejecutarphp artisan key:generate.
    Recursos Vite ausentes Mensaje de error y terminal npm Ejecutarnpm install y npm run dev, o npm run build.
